JSFKit is the home of JSF, the JSON Spreadsheet Format, and the tools for working with it. Our aim is to help developers read and write Excel XLSX files by handling the inconsistencies and quirks of the XLSX format. JSFKit projects use web technologies rather than proprietary technologies. Find out more on the [JSFKit website](https://jsfkit.github.io/).

---

Development of JSFKit is sponsored by [GRID](https://grid.is/), the spreadsheet engine for AI agents.
